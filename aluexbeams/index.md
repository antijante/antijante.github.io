# Aluex Beams

Project notes from Antijante on the new website for [Aluexbeams](https://aluexbeams.com). The site is still being built and is not live. This is not official Aluexbeams information, so use aluexbeams.com and its data sheets for anything about the products.

## What we are building

A WooCommerce site to replace the current Shopify shop. Built on a block theme, English first, with room for more languages later. Old addresses keep working through redirects, so existing links and search results still lead somewhere useful.

## Product range on the new site

24 products in four categories, using the names on the current site.

- **Aluminium X-spreaderbeams:** Aluex 2, 5, 10, 10+, 15, 18+ and 20.
- **Straight Spreaderbeams:** Aluex STR5, STR9, STR9+, STR15 and STR25.
- **Steel Spreaderbeams:** Aluex 30 and 50.
- **Accessories:** Aluex Lifter, Aluex Link 3, 10, 17 and 25, three Quick Release Hooks, and STR15 and STR25 Center Parts.
